	<Card title="Install teaport" icon="rocket">

		brain, and the services, and ends with a self-test. See
		[Install teaport](/getting-started/installation/).

		{/* source: README.md:28-33 @1e5604c */}
	</Card>
	<Card title="Prepare the Jetson" icon="rocket">
		Check the JetPack release and trim the desktop before you run the
		installer. See [Prepare the Jetson](/getting-started/prepare-the-jetson/).

		{/* source: docs/INSTALL.md:5-11 @1e5604c */}
	</Card>
	<Card title="Configure teaport" icon="setting">
		Point the brain at its large language model. Change settings in the
		configuration page. A restart applies the change; nothing hot-reloads.
		See [Configure teaport](/guides/configuration/).

		{/* source: install.sh:1506-1507 @1e5604c; brain/teaport_brain/gateway_server.py:27 @1e5604c; brain/teaport_brain/config_ui.py:27-28 @1e5604c */}
	</Card>
	<Card title="Set up phone calls" icon="phone">
		Answer phone calls on the device over a SIP trunk. `teaport sip configure`
		sets the line up. See [Set up phone calls](/guides/phone-calls/).

		{/* source: docs/CONFIG.md:370-375 @1e5604c; cli/teaport:9 @1e5604c */}
	</Card>
	<Card title="Connect the device to Wi-Fi" icon="wifi">
		If the device has no internet connection, its Wi-Fi setup opens a
		temporary setup network. Join it from a phone, pick your Wi-Fi network,
		and type the password. See
		[Connect the device to Wi-Fi](/guides/wifi-setup/).

		{/* source: brain/teaport_brain/wifi_setup.py:3-5 @1e5604c */}
	</Card>
